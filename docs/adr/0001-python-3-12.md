# ADR 0001 — Python 3.12 everywhere, managed by uv

Date: 2026-10-10 · Status: accepted · Source: PRD §10.1

**Decision.** One Python (3.12, installed by `uv`), one lockfile (`uv.lock`), never the system
Python. The lockfile resolved on this date to exactly the versions in PRD §10.2.

**Why.** Widest binary-wheel coverage for the scientific stack on x86_64 and aarch64 (Raspberry Pi,
Docker on Apple Silicon). The development machine's system Python is 3.14 and is not used.

**Consequences.** `requires-python = ">=3.12,<3.13"`. Upgrades only through a `chore(deps)` change
that re-runs the whole quality gate.
